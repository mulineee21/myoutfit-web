## ✨ Características de la Web

- 💎 **Estética Glassmorphism:** Transparencias con `backdrop-filter: blur(24px)`, reflejos especulares y paleta dark cósmica en tonos violeta y magenta.
- 📱 **Simulador de Smartphone Interactivo:** Mockup en vivo de la app donde se puede probar el selector de ocasiones, el recomendador con Gemini IA, el armario digital, lookbook y diario.
- 🎮 **Playground Interactivo:** Permite a los visitantes simular una recomendación de outfit directamente en la web.
- 📲 **Descarga con Código QR:** Incluye código QR SVG directo para escanear y descargar el APK en el móvil.
- 🔒 **Verificación de Integridad:** Hash SHA-256 copiable en 1 clic y guía de instalación para Android.
